# 医学院课表（手机版网页 / PWA）

从上海交通大学医学院智能教学系统导出的 2026-2027 学年第一学期课表，做成了适合手机竖屏使用的课表页面：

- 按“周一 ~ 周日”的一周页排版，可左右滑动翻周、上下滚动看全天节次
- 彩色课程块：课程名 + 地点，点击弹出课程信息（课程代码 / 教师 / 时间 / 教室 / 内容）
- 课程块配色按课程稳定分配（同一门课始终同色）
- 支持“添加到主屏幕”，之后像 App 一样从桌面打开

## 本地运行

在项目目录启动服务器：

```bash
cd "医学院课表制作"
python3 -m http.server 8765 --bind 0.0.0.0
```

同一 Wi-Fi 下，用 iPhone Safari 打开：

```
http://192.168.71.113:8765/
```

> 如果连不上，把 `192.168.71.113` 换成你电脑当前的局域网 IP（系统设置 → Wi-Fi → 详细信息里查看），并允许 Python 通过 macOS 防火墙。

## 添加到 iPhone 主屏幕

1. Safari 打开上面的地址
2. 点底部“分享”按钮
3. 选择“添加到主屏幕”
4. 命名后添加，之后从桌面点图标即可全屏打开

## 数据说明

- 数据文件：`data/schedule.json`（生成于 2026-09-04）
- 来源：医学院智能教学系统 `/Home/GetCurriculumTable`，账号对应的 2025 级临床医学八年制（法语）班课表
- 如需在新学期/课表变动后更新，重新抓取该接口后替换 `data/schedule.json` 即可
